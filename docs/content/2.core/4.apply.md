---
title: Apply
description: Resolve translations for segments and observe what happened to each one.
---

Adapters apply translations to documents, and the core supplies the pieces they share: looking up a translation, validating it, putting the protected spans back, and reporting what happened.

## Translations

A `Translations` value is a `Map` from hash to a translated skeleton or a `TranslationRecord`, or a function that returns one for a segment. A bare skeleton is accepted, so you can apply plain strings as well as full records.

## Resolving

`resolveTranslation(segment, translations)` returns one of:

| Status | Meaning |
| --- | --- |
| `missing` | There is no translation |
| `rejected` | A reviewer rejected the record (error code `rejected`) or the text failed [validation](/core/validation). `errors` says why |
| `ok` | `skeleton` is the validated translation, `text` has the current source's protected spans put back, and `warnings` lists warnings |

Rejected and missing segments keep their source text in the output. The `text` of an `ok` resolution always comes from the current source's placeholders, which is why a translated page links where the source links today.

## Reports

`createReport()` makes an empty report, and `tally(report, segment, resolution)` counts a resolution. The finished `ApplyReport` has `applied`, `missing` and `rejected`, where `rejected` lists `{ hash, file, index, errors }` for each segment.

## Apply events

The adapters' `apply` functions accept `onSegment`, called with an `ApplySegmentEvent` for each segment in extraction order:

| Field | Description |
| --- | --- |
| `segment` | The source segment, with its `hash` and `words` |
| `outcome` | `translated`, `missing`, `rejected` or `skipped`. `skipped` means no translation and nothing to translate |
| `errors` | Why a `rejected` translation wasn't applied. Empty otherwise |
| `record` | The record the lookup returned, if any |
| `status` | What a reader sees, as from `recordStatus`. A translation given as a bare skeleton has no status |
| `target` | For block-level segments, a handle whose `setAttribute(name, value)` sets an attribute on the output node. `null` for frontmatter, props, image alts, code labels and code comments |

Segments that aren't translated keep their source text.

`wordsByStatus(events)` sums the words of segments by status, which gives per-page coverage. `createSegmentEvent(segment, resolution, target)` builds an event for adapter authors.
