`@diglot/core` is the parser-neutral center of diglot. It defines the segment model, the placeholder form and hashing, translation validation, the helpers that adapters use to apply translations, segment and sentence diffs, translation records, and the policy, glossary and config types. It has no markdown parser dependency: [adapters](/adapters/overview) such as comark and mdast produce segments for it.

::package-info{name="@diglot/core" directory="packages/core"}
::

The core imports no Node built-ins, so it runs in browsers and edge runtimes as well as Node.js. That makes it possible to validate or apply translations in a worker that serves your documentation.

## Who uses it

You use the core directly when you write an adapter for another markdown parser, when you validate or apply translations in your own renderer, or when you work with records. If you only run the workflow, the [CLI](/workflow/cli/overview) and the [Action](/workflow/action/overview) use it for you.
