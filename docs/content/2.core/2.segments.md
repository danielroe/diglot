---
title: Segments
description: Turn parsed inline content into a segment with a skeleton, placeholders and a hash.
---

An adapter converts each translatable unit of a document into a `SegmentDraft`, and `buildSegment` turns the draft into a `Segment`. The core never sees parser nodes, only the small inline representation described below.

## The inline representation

The inline content of a draft is a list of nodes:

| Node | Meaning |
| --- | --- |
| `text` | Literal text |
| `strong`, `emphasis`, `delete` | Emphasis with children |
| `link` | A link with children and the markdown around its text (`open` and `close`) |
| `atomic` | A protected span with its markdown `source` and a `kind`: `code`, `link`, `component`, `html`, `image`, `break`, `binding` or `other` |

Nodes may carry a `data` field that the core passes through untouched, so an adapter can map a placeholder back to its own node.

## Building a segment

```ts
import { buildSegment } from '@diglot/core'

const segment = buildSegment({
  kind: 'paragraph',
  content: [
    { type: 'text', value: 'Nuxt is powered by ' },
    { type: 'link', open: '[', close: '](https://nitro.build)', children: [{ type: 'text', value: 'Nitro' }] },
    { type: 'text', value: '.' },
  ],
  context: { headingTrail: [], containers: [] },
  position: { startLine: 1, endLine: 1, precision: 'node' },
}, { file: 'intro.md', index: 0 })

segment.skeleton // 'Nuxt is powered by {0}Nitro{/0}.'
segment.hash // sha256 of the skeleton, truncated to 16 hex characters
```

`buildSegment` returns `undefined` for a unit without content. `buildSegments(file, drafts, policy?)` builds a whole file and numbers the segments in order. Passing a policy lets its `salt` function add a [context salt](/guide/concepts/skeletons-and-hashes) to ambiguous segments.

`prepareSegment` takes the same arguments and returns `{ segment, nodes }`, where `nodes[id]` is the link or atomic node behind placeholder `id`. Adapters use it to rebuild a translated unit from the current source nodes. With `resolvedSources: false` in the options, for drafts whose protected spans carry no markdown, the segment's `text` equals its `skeleton` and its `sourceHash` equals its `hash`.

A draft with string content is plain by default, and one with inline nodes is markdown. Set `format` to override that. In plain format, text is not escaped and emphasis is flattened.

## The segment

| Field | Description |
| --- | --- |
| `hash` | The SHA-256 of the skeleton, and of the salt when there is one, truncated to 16 hex characters |
| `sourceHash` | The same hash computed over `text`, so it changes when protected spans change |
| `kind`, `format` | See [segments](/guide/concepts/segments) |
| `skeleton` | The placeholder form, the only thing a translator or model sees |
| `text` | The skeleton with the placeholders put back |
| `placeholders` | `{ id, type, source, close?, name?, hidesText? }` for each placeholder |
| `words` | The number of words outside placeholders. `0` means there is nothing to translate |
| `context` | The file, heading trail, index, containers and detail |
| `position` | Start and end line, and whether they are exact (`node`), those of the enclosing top-level block (`block`) or unknown (`file`) |
| `salt` | The context salt, when set |

## Skeleton helpers

| Function | Description |
| --- | --- |
| `hashSkeleton(skeleton, salt?, format?)` | The identity hash of a skeleton |
| `toSkeleton(nodes, format?)` | The skeleton, placeholders and the node behind each placeholder |
| `fromSkeleton(skeleton, placeholders)` | Puts protected spans back into a possibly translated skeleton |
| `parseSkeleton(skeleton, placeholders, format?)` | Parses a validated skeleton into text, emphasis and placeholder nodes, resolving escapes |
| `normalise(nodes)` | Collapses whitespace and trims, so re-wrapping lines doesn't change the skeleton |
| `escapeText(value)` | Backslash-escapes characters that markdown or MDC would interpret |
| `encodeInvisibles(value)` | Writes soft hyphens and no-break spaces as `&shy;` and `&nbsp;` |
| `countWords`, `isPlaceholderOnly`, `plainText`, `toMarkdown` | Small helpers on skeletons and nodes |
| `pseudoTranslate(skeleton, format?)` | A valid pseudo-translation: text runs are wrapped in `⟦ ⟧` and their vowels accented |

`pseudoTranslate` is useful to see in a rendered page which text is translatable and which is not, since placeholders, emphasis markers and escapes are kept.
