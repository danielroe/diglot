title: Angular app
description: Run a small Angular app in English, French and Turkish that applies diglot bundles in the browser and while it prerenders.
---

`examples/angular` in the diglot repository is a small [Angular](https://angular.dev) app, written in English and translated into French and Turkish. Its pages are Markdown files, and the [Angular providers](/integrations/angular) apply the bundle of `translations`, a translations repository that lives inside the app, when a page loads. Every page is prerendered in all three locales, and the browser picks up the prerendered documents without fetching them again.

## Run it

Install the dependencies from the root of the diglot repository, so that the example uses the local diglot packages. Then start the dev server from the example's directory:

```bash
pnpm install
cd examples/angular
pnpm start
```

`pnpm start` and `pnpm build` run `diglot extract` and `diglot build` first, so the policy snapshot and the bundle always match the pages. When you build the app with `pnpm build`, you get nine pages in `dist`: `/en`, `/en/guide` and `/en/about`, and the same three under `/fr` and `/tr`.

## What it contains

| File | Purpose |
| --- | --- |
| `src/app/app.config.ts` | `provideDiglot()` with the bundle and source URLs, the policy snapshot, the `mdast` parser and `withDiglotRouteLocale()` |
| `src/app/app.routes.ts` | The `/:locale` and `/:locale/:slug` routes |
| `src/app/app.routes.server.ts` | The parameters that prerender every page in every locale |
| `src/app/page.ts` | The page component: `diglotDocument()`, the navigation, the language menu and the partly-translated notice |
| `src/app/markdown.ts` | Renders a page with marked and points its relative links to the same locale |
| `src/content/docs/` | The English source pages |
| `translations/` | The translations repository: `diglot.config.ts`, `sources.yml` and the French and Turkish records |
| `angular.json` | Serves the bundle under `/translations` and the source pages under `/docs` |

The French and Turkish records translate every page except one paragraph of the about page. That page shows the paragraph in English, and a notice that it is only partly translated, which comes from the report of `diglotDocument()`.
