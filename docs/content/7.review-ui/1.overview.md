::note
`@diglot/x18n` is experimental and is built against x18n 0.1.8.
::

`@diglot/x18n` is a plugin for [x18n](https://github.com/x18n-dev/x18n), a tool for managing translations with a CLI, an editor and a browser UI. The plugin shows a diglot translations repository in those tools: each segment hash is a key, the source manifests hold the source-locale messages, each record file holds one translation, and every place where a segment occurs in a source document is a usage of its hash.

Use it when you want reviewers to work in x18n's UI instead of editing JSON files.

::package-info{name="@diglot/x18n" directory="packages/x18n" install="pnpm add -D @diglot/x18n @x18n/cli"}
::

```ts [x18n.config.ts]
import diglot from '@diglot/x18n'

export default {
  plugins: [diglot()],
}
```

Put `x18n.config.ts` next to `diglot.config.ts`. The plugin takes two options: `root`, the translations repository relative to the x18n project root (default: the project root), and `sourceLocale`, the locale of the source documents (default `en`).

## Usages

Usages come from the files under `.diglot/sources/<source>`, which [`diglot checkout`](/workflow/cli/checkout) exports as plain files at each source's configured ref. The plugin sets `usage.include` to those documents and `usage.gitignore` to `false`, so the git-ignored exports in the [Nuxt example](/guide/examples/nuxt-translations) are scanned. Run `checkout` before you use x18n.
