---
title: status
description: Report how many segments and words of each source are translated, and how far they are reviewed.
---

`diglot status` compares the manifests with the records of each locale and counts segments and words by [status](/guide/concepts/review-and-status). It answers the question of how much of a source a reader sees translated, and how much of that a person has looked at.

```bash
pnpm dlx @diglot/cli status [--locale fr] [--json]
```

## Options

| Option | Default | Description |
| --- | --- | --- |
| `--locale` | all locales | Report only this locale |
| `--json` | off | Print the report as JSON |
| `--cwd` | `.` | The translations repository root |

## Reading the output

The report has one line per locale and source:

```text
fr
  nuxt-main: 2310 segments, 41200 words, 12.5% of words reviewed (verified 120, edited 200, pending-review 40, machine 1900, untranslated 50)
```

The numbers are examples of the format. The statuses are `verified`, `edited`, `pending-review`, `machine`, `rejected` and `untranslated`. `rejected` counts records that a reviewer rejected and translations that fail validation. The percentage is the share of words that are `edited` or `verified`.

Segments without letters outside placeholders have nothing to translate and are left out of all counts.

## JSON

With `--json`, the report is keyed by locale and then by source. Each entry has `segments`, `words`, `reviewedWords` and `byStatus`, which maps each status to its `segments` and `words`.
