`@diglot/mt` writes the first draft of translations. It translates new segments in page-sized batches, updates an existing translation when its source changes while altering as little as possible, puts your glossary and style rules into the prompt, and runs model-free QA checks on every output. It is built on the [AI SDK](https://ai-sdk.dev), so any `LanguageModel` works.

::package-info{name="@diglot/mt" directory="packages/mt" install="pnpm add @diglot/mt @diglot/core"}
::

You rarely call this package directly, because the [Action](/workflow/action/overview) already uses it. Use it when you build your own pipeline or want to translate segments from a script.

## Choosing a model

Pass the `model` option as a `LanguageModel` from any AI SDK provider, or as a model id string, which is resolved through the [Vercel AI Gateway](https://vercel.com/ai-gateway). When you leave `model` out, the id is read from the `DIGLOT_MT_MODEL` environment variable, and if that isn't set either, the call throws. The gateway reads its key from `AI_GATEWAY_API_KEY`.

`gatewayModel` builds a gateway model with explicit settings:

```ts
import { gatewayModel } from '@diglot/mt'

const model = gatewayModel('anthropic/claude-sonnet-5.5', { apiKey })
```

## What is in the package

| Function | Purpose |
| --- | --- |
| [`translateSegments`](/machine-translation/translate-segments) | Translate new segments in batches, with retries on QA errors |
| [`updateTranslation`](/machine-translation/update-translation) | Carry over or minimally update a translation after its source changed |
| [`runQa`](/machine-translation/qa-checks) | Check a translation against its source without calling a model |
| [`gatewayModel`](/machine-translation/overview#choosing-a-model) | Build a Vercel AI Gateway model |
| `emptyUsage`, `addUsage` | Create and sum [usage](/machine-translation/usage-and-cost) records |

The prompts record a `PROMPT_VERSION`, which is stored as `promptVersion` in the `mt` block of each record so that you can tell which prompt produced a text.

## Options shared by the functions

| Option | Default | Description |
| --- | --- | --- |
| `locale` | required | The target locale, such as `fr` |
| `model` | `DIGLOT_MT_MODEL` | A model instance or a gateway model id |
| `glossary` | none | A [glossary](/machine-translation/glossary-and-style) |
| `style` | none | A [locale style](/machine-translation/glossary-and-style) |
| `subject` | `technical documentation` | What is being translated, used in the prompt |
| `sourceLocale` | `en` | The language of the source |
| `qaRetries` | `1` | Retries for segments that fail an error-level QA check |
| `pricing` | none | USD per million input and output tokens, for providers that don't report a cost |
| `signal` | none | An `AbortSignal` that cancels requests |
