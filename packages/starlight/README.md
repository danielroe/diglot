# @diglot/starlight

A [Starlight](https://starlight.astro.build) plugin for [diglot](../../README.md) translations. It sets up [`@diglot/astro`](../astro) the way Starlight works: your locales come from the Starlight config, the docs collection loads the same files as Starlight's own loader, and the components and frontmatter fields that Starlight shows are translated.

```bash
pnpm add @diglot/starlight
```

Add the plugin to your Starlight config, with `translations`, the directory of the translations repository relative to the project root:

```js
import starlight from '@astrojs/starlight'
import diglot from '@diglot/starlight'
import { defineConfig } from 'astro/config'

export default defineConfig({
  integrations: [
    starlight({
      title: 'My docs',
      locales: {
        root: { label: 'English', lang: 'en' },
        fr: { label: 'Français', lang: 'fr' },
      },
      plugins: [diglot({ translations: './translations' })],
    }),
  ],
})
```

Then use `diglotDocsLoader()` in place of `docsLoader()` in `src/content.config.ts`. It loads the same files and accepts the same `generateId` option:

```ts
import { docsSchema } from '@astrojs/starlight/schema'
import { diglotDocsLoader } from '@diglot/starlight'
import { defineCollection } from 'astro:content'

export const collections = {
  docs: defineCollection({ loader: diglotDocsLoader(), schema: docsSchema() }),
}
```

In the translations repository, set `parser: 'satteri'` and `policy: starlightPolicy` from `@diglot/core`, so that the titles of asides, the props of Starlight's components and Starlight's frontmatter fields are translated.

Translated pages show up in the autogenerated sidebar in the same order as their sources, and pages that nobody has translated yet fall back to Starlight's notice. With `editLink.baseUrl`, the edit link of a translated page leads to its source page, and with `lastUpdated`, a translated page shows the date of its newest translation.

The package needs Starlight 0.42, Astro 7 and Node.js 22.23.4 or later.

See the [Starlight integration docs](https://diglot.sh/integrations/starlight) for everything your readers see and the limitations.
